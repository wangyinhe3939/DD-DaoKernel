# DD-DaoKernel
> I do not want Codex to merely look smarter. I want it to guess less, overreach less, and know when to stop.

DD-DaoKernel distills operational ideas inspired by the Dao De Jing into a decision kernel for coding agents.

`Evidence → Name → Desire → Arena → Action → Autonomy → Stop → Boundary`

Its four agents separate decision, observation, execution and veto powers. It does not predict the future. It makes blind spots, assumptions, second-order effects, reversibility and stop conditions explicit.

**The point is not to do less. The point is to avoid the extra move that creates more problems than it solves.**
